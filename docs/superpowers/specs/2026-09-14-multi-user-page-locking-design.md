# 多用户账号、按页保存与页面锁设计

日期：2026-09-14

## 目标

将当前单用户、任务级保存的图纸核对系统升级为多人协作系统：用户可以自行注册并访问全部图纸任务；任务记录创建人；同一解析任务允许多人同时核对不同页，但任意时刻一页只能由一个浏览器标签页编辑；保存、冲突检测和审计均以页为单位。

## 范围

本次包含：

- 用户注册、登录、退出、会话恢复和受保护 API。
- 任务创建人记录与展示。
- 页级修订号、页级保存接口和兼容历史任务的数据迁移。
- 持久化页面租约锁、续租、释放、过期回收和占用提示。
- 前端未保存状态、切页保存、关闭提示和锁状态显示。
- 多页批量操作的全页锁约束。
- 后端与前端自动化测试、部署配置和文档。

本次不包含：

- 不同用户对同一页修改的自动合并。
- 角色和细粒度任务权限；所有有效账号都能访问全部任务。
- 邮件验证、找回密码、企业 SSO 和第三方登录。
- 实时光标或实时共同编辑。

## 总体架构

沿用当前同源前后端、单 API 服务进程、独立分析 Worker 和共享数据卷。账号、会话和页面锁存入现有 SQLite 数据库；解析结果仍以任务目录中的 `result.json` 为权威数据文件。API 进程继续用进程内互斥锁串行化 `result.json` 的读取和原子替换。Docker Compose 当前只运行一个 API 实例，因此该约束成立；未来若扩展多个 API 实例，必须先把页面内容迁入数据库或增加跨进程文件锁。

页面锁解决编辑所有权，页修订号解决陈旧提交。两者缺一不可：锁会因网络中断而过期，而修订号确保旧客户端即使持有过期内容也不能覆盖新内容。

## 数据模型

### users

- `user_id TEXT PRIMARY KEY`：随机 UUID。
- `username TEXT NOT NULL`：显示名称。
- `username_key TEXT UNIQUE NOT NULL`：大小写归一化后的唯一键。
- `password_hash BLOB NOT NULL`。
- `password_salt BLOB NOT NULL`。
- `password_parameters TEXT NOT NULL`：JSON 格式的 scrypt 参数，便于以后升级。
- `disabled INTEGER NOT NULL DEFAULT 0`。
- `created_at TEXT NOT NULL`。
- `last_login_at TEXT`。

用户名去除首尾空白，长度 3 至 40 个字符；密码长度 10 至 128 个字符。密码使用 Python 标准库 `hashlib.scrypt` 和独立随机盐计算，不保存或记录明文。

### user_sessions

- `session_hash TEXT PRIMARY KEY`：随机会话令牌的 SHA-256，不保存原始令牌。
- `user_id TEXT NOT NULL`。
- `created_at REAL NOT NULL`。
- `last_seen_at REAL NOT NULL`。
- `expires_at REAL NOT NULL`。

原始令牌仅通过 `HttpOnly` Cookie 发送。会话默认七天到期；有效请求按限制频率刷新最后访问时间，但不会无限延长绝对到期时间。退出时删除会话记录并清除 Cookie。

### jobs 扩展

- `creator_user_id TEXT`：允许为空以兼容历史任务。
- `creator_username TEXT`：创建时的用户名快照，账号以后改名也保留任务审计信息。

新建任务时从当前认证会话写入这两个字段，同时写入 `job.json` 和初始 `result.json`。任务列表和详情响应返回 `createdBy` 对象；历史任务返回 `null` 并在界面显示“历史任务”。

### page_locks

- `job_id TEXT NOT NULL`。
- `page_number INTEGER NOT NULL`。
- `owner_user_id TEXT NOT NULL`。
- `owner_username TEXT NOT NULL`：占用提示快照。
- `client_instance_id TEXT NOT NULL`：每个浏览器标签页在 `sessionStorage` 中生成的 UUID。
- `lock_token_hash TEXT NOT NULL`：随机锁令牌的 SHA-256。
- `acquired_at REAL NOT NULL`。
- `heartbeat_at REAL NOT NULL`。
- `expires_at REAL NOT NULL`。
- 主键为 `(job_id, page_number)`。

锁默认租约 90 秒，客户端每 30 秒续租。获取、续租和释放都在 SQLite `BEGIN IMMEDIATE` 事务内完成。获取时可原子替换已过期锁；未过期锁只能由相同用户、相同客户端实例和正确令牌续租。

### 页级字段

`result.json` 的每个页面增加：

- `reviewRevision INTEGER NOT NULL DEFAULT 0`。
- `reviewedBy`：最近保存者的用户 ID 和用户名。
- `reviewedAt TEXT`：最近保存时间。

读取历史结果时缺少 `reviewRevision` 视为 0，无需批量重写历史文件。

任务级 `revision` 暂时保留用于兼容旧草稿和只读展示，但不再参与页面编辑保存，也不因页保存而递增。前端停止调用旧的整任务保存接口；旧接口对普通任务返回迁移提示，避免旧客户端覆盖新数据。

## 认证与安全

新增接口：

- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/auth/me`

除健康检查、静态前端资源、注册和登录外，任务、上传、导出、审计、队列和文件接口均要求有效会话。Worker 不经 HTTP 调用这些接口，不受浏览器认证影响。

Cookie 名为 `drawing_marker_session`，设置 `HttpOnly`、`SameSite=Lax`、`Path=/`；通过环境变量控制生产环境的 `Secure` 标志。所有改变状态的请求校验 `Origin` 与当前 `Host` 同源；不接受跨站表单提交。登录和注册返回统一、克制的错误信息，密码和会话令牌不进入审计日志。

开放注册意味着知道系统地址的人都可创建账号并访问所有任务，因此 README 和部署配置必须明确要求 TLS、网络边界和反向代理限流。应用内对注册和登录按来源地址做轻量速率限制，防止简单暴力尝试。

## 页面锁 API

新增接口：

- `GET /api/jobs/{jobId}/page-locks`：返回未过期锁摘要，不返回锁令牌。
- `POST /api/jobs/{jobId}/pages/{page}/lock`：获取锁；请求包含 `clientInstanceId`，成功返回原始 `lockToken`、持有人和到期时间。
- `PUT /api/jobs/{jobId}/pages/{page}/lock`：使用 `clientInstanceId` 和 `lockToken` 续租。
- `DELETE /api/jobs/{jobId}/pages/{page}/lock`：释放锁。

竞争获取未过期页面返回 HTTP 423，响应包含占用者用户名和 `expiresAt`。不存在的任务或页返回 404。锁过期、令牌错误或锁已被接管时，保存和续租返回 423，客户端立即转为只读并保留未保存内容。

读取任务工作区时不隐式获取锁。客户端确定要显示的初始页后显式获取，避免预加载和后台请求占锁。

## 页级保存 API

新增：

```text
PUT /api/jobs/{jobId}/pages/{pageNumber}
```

请求包含：

- `page`：且仅包含该页的完整可编辑页面数据。
- `basePageRevision`。
- `clientInstanceId`。
- `lockToken`。

保存流程在服务端互斥区内按顺序执行：

1. 验证会话、任务、页码和请求大小。
2. 从 SQLite 验证当前未过期锁及锁令牌。
3. 读取最新 `result.json`。
4. 比较页面的 `reviewRevision` 与 `basePageRevision`。
5. 使用现有候选数据校验逻辑校验单页。
6. 只替换目标页，设置新修订号、保存者和时间。
7. 原子替换 `result.json`。
8. 返回新的页修订号和时间。

页修订不一致返回 HTTP 409，但不会覆盖服务器内容；响应包含服务器当前修订号。不同页面的保存虽然在写文件瞬间短暂串行，但不共享修订号，因此不会互相冲突。

标识的实际位置、编号和单个候选外观属于页面数据，随页面保存。当前任务级 `markerStyle` 和 `componentMarkerStyles` 改为客户端默认外观偏好，保存到用户浏览器；它们不再通过页保存覆盖整个共享任务。导出优先使用候选自身已经保存的外观，缺失时使用任务分析时的默认值。

## 前端状态与交互

### 登录入口

应用启动先调用 `/api/auth/me`。未登录时显示登录/注册界面；成功后再加载任务数据。Header 显示当前用户名和退出入口。会话失效的 API 请求统一触发重新登录，但保留当前内存中的未保存页面。

### 打开页面

每个标签页在 `sessionStorage` 保存独立 `clientInstanceId`。进入任务后：

1. 获取锁摘要。
2. 对目标页调用获取锁接口。
3. 成功后加载/显示页面并启动 30 秒心跳。
4. 失败时保持原页面，提示“第 N 页正在由某用户核对”。

页码按钮显示空闲、本人占用、他人占用三种状态。锁摘要仅用于提示，最终能否进入以原子获取接口结果为准。

### 修改与保存

删除基于 900 毫秒和 2 秒定时器的两套自动保存。任何编辑只把当前页标记为 dirty，不访问 IndexedDB 或后端。

正常切页流程：

1. 如果当前页 dirty，保存浏览器恢复草稿中的当前页，再调用页保存接口。
2. 保存成功后清除 dirty。
3. 释放当前页锁。
4. 获取目标页锁。
5. 切换并渲染目标页。

当前页无修改时直接释放并获取下一页。手动“保存”仅保存当前页。快速连续点击页码通过现有 generation 机制丢弃过期导航结果，并确保同一时刻只有一条切页保存链。

保存失败时默认留在当前页、保留锁和 dirty 状态，并显示重试提示。浏览器草稿只在切页保存开始、手动保存或保存失败时写入，不再按编辑动作持续写入。

### 关闭与异常

dirty、保存中或锁状态不确定时注册 `beforeunload` 提示。用户确认离开后通过 `fetch(..., {keepalive: true})` 尽力释放锁；该请求不保证成功，所以服务端租约到期是最终兜底。无未保存修改时关闭不提示。

心跳连续失败后界面提示连接异常，但在租约到期前不立即丢弃编辑内容。服务端明确返回锁丢失时页面转为只读，用户可复制/保留浏览器草稿，不允许无锁提交。

### 工程切换和退出

切换设计图工程等同离开当前页，先执行同一保存与释放流程。退出登录前也必须处理 dirty 页面；保存成功或用户明确放弃后才退出。

## 批量操作

“全部重编”等会修改多页的操作必须调用批量锁接口原子获取所有涉及页面：

```text
POST /api/jobs/{jobId}/page-locks/batch
```

只要任一页面被其他客户端占用，整个批量获取失败且不保留部分锁，响应列出冲突页和占用者。成功后执行操作并逐页保存，最后释放批量获得的锁。批量过程出现失败时保留未保存草稿并继续持有尚未到期的锁供重试。

导出、查看和下载属于只读操作，不获取页面锁。删除任务、重新分析等任务级破坏性操作在存在任何有效页面锁时拒绝执行，并列出占用页面。

## 迁移与兼容

SQLite 初始化使用幂等迁移：检查并增加 `jobs.creator_user_id`、`jobs.creator_username`，再创建用户、会话和锁表。已有任务不需要重跑分析。

历史 `result.json` 页面缺少页修订号时按 0 处理；首次页保存后写入字段。旧浏览器草稿可以读取，但恢复后保存必须先登录、获取对应页锁，并使用服务器当前页修订号；草稿基于旧内容时由页级 409 阻止覆盖。

部署首次升级后没有账号，登录页允许直接注册首个账号。开放注册持续有效。

## 测试策略

后端测试覆盖：

- 注册、重复用户名、密码哈希、登录、退出、过期/禁用会话。
- 未认证访问受保护 API 被拒绝。
- 新任务正确记录创建人，历史任务兼容。
- 两个客户端竞争同一页只能一个成功。
- 不同页面可以由不同用户同时持锁并保存。
- 同一账号不同标签页仍互斥。
- 心跳续租、主动释放、过期接管和错误令牌拒绝。
- 无锁保存、错误页版本和陈旧页版本拒绝。
- 两个不同页面从同一初始任务状态保存均成功且互不覆盖。
- 批量锁全有或全无。

前端测试覆盖：

- 未登录只显示认证入口；注册/登录后恢复应用。
- 编辑只设置 dirty，不触发定时保存。
- 切页按保存、释放、获取顺序执行。
- 被锁页不能进入并显示占用者。
- 当前页无修改时切页不保存。
- 保存失败保持当前页和 dirty 状态。
- dirty 时关闭提示，保存成功后不提示。
- 心跳丢锁后转只读。
- 快速切页不会重复保存或泄漏锁。

完成前运行完整后端测试、完整前端测试和前端生产构建。

## 验收标准

- 用户可注册、登录、退出，会话刷新后仍有效。
- 登录用户能访问全部任务，任务列表和详情显示创建人。
- 两名用户能同时编辑同一任务的不同页并独立保存。
- 两个不同用户或两个浏览器标签页不能同时打开同一页进行编辑。
- 编辑动作本身不触发浏览器或后端保存；切页和手动保存各触发一次当前页保存。
- 同页陈旧提交不能覆盖新内容，不同页之间不再出现任务级 revision 冲突。
- 浏览器异常退出后锁最多 90 秒自动释放。
- 当前页有未保存修改时关闭/刷新会提示。
- 历史任务和历史草稿可以读取，升级不要求重新分析图纸。
