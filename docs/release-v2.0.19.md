# v2.0.19 更新与部署说明

构建编号：`20261012-marker-editor-release`。

## 本次更新

- 恢复独立框尺寸设置及长编号自动缩小文字的行为，圆形、菱形和分栏圆形不再随编号长度扩大；统一画布、布局优化和 PDF 导出的尺寸规则。
- 修正分类外观与选中对象外观的输入框间距。
- 右侧图纸标识区域提供批量修改表格，支持页码范围、类型和搜索筛选；表头选择全部筛选结果，跨表格分页生效。
- 表格每页 15 行，分页栏独立，最多显示 5 个数字页码。
- 包含当前工作区的拖拽新增、页面核对锁处理及内存/绘制改进。

## 更新已有 Docker 部署

1. 等待当前识别任务完成，让用户保存核对结果；按原部署流程备份数据。
2. 将 ZIP 解压到原部署项目目录，覆盖程序文件。保留服务器原有 `.env` 和数据卷；本包不包含 `.env` 和运行数据。
3. 在服务器原有 `.env` 中仅更新以下两项，保留其他配置：

   ```dotenv
   DRAWING_MARK_RECOGNITION_VERSION=2.0.19
   DRAWING_MARK_RECOGNITION_BUILD_ID=20261012-marker-editor-release
   ```

4. 在原项目目录执行：

   ```bash
   docker compose build drawing-mark-recognition
   docker compose up -d --force-recreate
   docker compose ps
   curl http://127.0.0.1:8768/api/health
   ```

   如果原部署修改了端口，请使用原端口。健康响应应显示上述版本、构建编号和 Worker 状态。
5. 刷新浏览器，检查已有任务恢复、批量筛选与保存、字号调整和 PDF 导出。

不需要删除数据卷或重新创建任务。请勿执行 `docker compose down -v`。

## 验证结果及已知问题

- 2026-10-13 发布复核：前端全量测试 255 项通过，生产构建通过（使用独立输出目录，避开本地 dist 目录权限限制）；四种框型的字号变化和批量保存已有浏览器验证记录。
- 后端全量测试共 203 项：200 项通过、2 项跳过、1 项失败。
- 失败项：`test_target_page_7_recovers_two_closed_flanges_around_the_valve`。本地真实图纸第 7 页预期识别 2 个法兰，当前识别 3 个；该识别函数及测试本轮没有修改。本包未尝试修正这条识别回归，部署后应留意对应图纸的法兰核对。
- 归档包含源码及依赖锁文件，Docker 构建时重新生成前端资源。归档旁的 `.sha256` 文件可用于校验传输完整性。
