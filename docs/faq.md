# 常见问题与操作速查

本页对应当前工作台界面。详细流程见[使用指南](usage.md)，部署问题见[部署指南](deployment.md)。教程入口为顶部指南针；快捷键以当前速查面板为准，下文列出默认按键。

## 智能编号、推入解析队列和直接落图有什么区别？

智能编号与推入解析队列都会识别图元、处理配置的对照资料并自动编号，前者用于当前操作，后者用于提前准备结果。直接落图只上传设计 PDF、优化底图并创建人工标注任务，不执行识别、对照解析或自动编号；完成后从“落图任务”恢复，在画布人工新增。

已有任务打开时不能再次创建任务，先保存并关闭。选择 PDF 对照解析时，必须先选择对照 PDF；没有参考资料则选择仅图元。

## 怎样人工新增标识？按 A 没有反应怎么办？

先确认任务已完成、当前页可编辑，再按 W/V/F/S/M 进入焊口、阀门、法兰、支架或其他标识模式。默认“按键新增”下，将鼠标移到画布中的定位点并按 A；右侧新增引线长度决定默认引线。

系统设置 → 标识默认设置 → 标识编辑操作方式若选了“拖拽新增”，A 不执行新增。此时用左键从定位点拖向编号框位置，松开创建对象，拖动期间预览引线；使用中键平移。拖拽方式下引线长度设置隐藏，长度和方向由拖动决定。单击或取消拖拽不会创建对象。

## 人工新增为什么从设定的起始数字重新编号？

人工新增与自动识别使用独立序列，不查找任务已有编号。首次新增严格使用右侧设定的起始数字：焊口在同一次连续编辑中跨页递增，阀门、法兰、支架和其他标识按页分别计数，返回已经新增过的页面时继续该页序列。修改前缀、后缀或起始数字，或者恢复另一任务，会重新计数。起始数字留空时只拼接前后缀。新增后检查是否与现有编号重复，必要时使用顺延编号或批量修改。

## 分栏圆形上下栏怎样设置？

外形选择分栏圆形后，右侧新增编号规则会分别显示上下栏的前缀、起始数字和后缀，新增时两栏各自递增。选中对象可在右侧编辑上栏、下栏；双击编号也支持两栏编辑。批量表格的“内容与状态”中，编号对应上栏，“下栏”对应第二行。

其他标识默认采用分栏圆形，框尺寸 28、字号 11；它仍属于其他标识，可按 M 模式新增、编辑和按区域删除，不影响普通焊口与管件分类。

## 长编号会把圆框撑大吗？为什么实际文字小于设置字号？

框尺寸与字号已恢复为独立设置。圆形、菱形和分栏圆形保持指定框尺寸，长编号会自动缩小文字，分栏圆形同时考虑上下栏；设置的字号是期望字号，空间不足时实际显示字号更小。可以增大框尺寸或缩短编号。矩形保留原有按编号长度扩展宽度的规则。

框尺寸允许 18–64，字号允许 7–24；已有任务的框尺寸继续生效，缺少框尺寸时恢复分类默认值。画布、布局优化和 PDF 导出共用尺寸规则。

## 系统默认外观、右侧分类外观和批量独立外观有什么关系？

| 设置入口 | 作用范围 |
| --- | --- |
| 系统设置 → 标识默认设置 | 当前用户以后新任务的默认值；修改某分类也同步该分类到当前任务 |
| 右侧分类标识外观 | 当前任务中跟随分类设置的普通标识，以及后续按该分类新增的对象 |
| 批量表格 → 标识外观 | 保存后只作用于改动的对象，优先于任务分类外观 |
| 选中其他标识 → 外观 | 当前选中的其他标识 |

右侧任务设置不会反向覆盖系统默认值。旧任务和草稿会恢复各自保存的设置。“默认”外形跟随系统中该分类的外形。分类设置里框尺寸和字号同一行，线宽和颜色同一行。

## 插入 F4 后怎样让原 F4、F5、F6 顺延？

选中新插入的 F4，点击右侧“顺延编号”或按默认 Ctrl+F。选中对象保持 F4，当前页其他同类、同前后缀且数字不小于 4 的对象加 1，原 F4/F5/F6 变为 F5/F6/F7。不会改动其他页或其他分类；编号必须含可顺延数字。Ctrl+Z 可撤销，快捷键可修改但必须保留 Ctrl。

## 批量表格全选为什么选中多于当前显示的 15 行？

表头复选框作用于全部筛选结果，跨表格分页生效。先设置页码、类型和搜索条件，查看“筛选结果”和“已选”数量，再全选。选择页码范围时包含两端，范围无效时不能全选。取消当前筛选结果只移除其中已选行，其他筛选条件下已经选中的对象继续保留。

## 怎样批量生成编号、调整框尺寸并保存？

1. 在已完成且可编辑的任务中打开右侧“批量修改标识”。打开前先保存画布待保存页面。
2. 筛选页码范围、类型和编号，勾选目标行；全选时确认数量。
3. 在“内容与状态”展开“统一修改选中标识”，设置前缀、后缀、起始数字与步长，点击“填入选中行”。编号顺序按原始图纸页码和表格顺序，起始数字可为 0，步长须为正整数。
4. 切换“标识外观”，对选中行设置框尺寸、字号等。统一修改中空白项保持不变；可直接逐行修改。参与标识的对象必须有编号。
5. 点击“保存批量修改”。只填入表格还没有提交；保存成功后成为对象的独立外观，可在对应页面撤销、重做。

## 批量保存有些页面失败，其他页面会丢失吗？

批量保存逐页检查核对锁和 revision。可保存的页面正常提交，被其他窗口占用或版本变化的页面不覆盖，失败修改保留在表格中。先处理锁占用；版本冲突应关闭并重新打开表格，在最新数据上重新修改。不要把旧版本反复提交。

退出有未保存修改的表格时，会提示保留或放弃，保存过程中不能退出。普通“保存”则依次提交所有待保存页面，任一页失败会停止后续提交并保留工作区；两种保存的处理方式不同。

## 怎样删除一片区域的标识并撤销？

按 D 进入区域删除，在画布框选，以对象定位点是否落入选框判断。处于 W/V/F/S/M 模式时只删除对应分类，默认模式删除所有分类；进入区域删除不会清除当前修改类型。Esc 退出，Ctrl+Z 撤销。只删一个对象可选中后按 Backspace。

## 重新优化当前页会重新识别或改号吗？

不会。它只排列当前页参与标识的对象，尽量避让文字、管线、锚点、其他框和引线；不改其他页。Worker 在任务完成前执行初始布局，拖动、改号、撤销或重做不会自动再次优化。需要时点击右侧“重新优化当前页标识位置”，也可撤销。

## 怎样保存、导出并恢复？

右侧底部“保存”提交当前工作区全部待保存页面；“保存并关闭”全部成功后释放锁、关闭工作区并返回队列。保存失败时保持打开并保留修改，按提示处理后重试。“导出修改版本”生成标识 PDF，包含可继续编辑的数据；参与标识的对象须有编号。当前工作台底部没有 CSV 导出菜单，CSV 数据导出由后端接口支持。

可从服务器完成任务、浏览器草稿或带内嵌数据的标识 PDF 恢复。浏览器草稿及 PDF 恢复会与服务器逐页比对，有冲突时按提示选择版本；草稿不等于服务端已经保存。教程任务只保存浏览器草稿，不修改内置示例。

## 看不到教程或队列入口、消息不显示怎么办？

从始终保留的系统设置齿轮进入“界面与 Header”，重新开启对应顶部按钮。操作信息与错误信息可独立关闭，当前默认均开启并在底部显示；已有用户的偏好继续保留。Tooltip 也有独立开关。

左右区域可分别显示并选择紧凑、标准或宽松宽度，也可点抽屉标题栏齿轮调整。工作区与文件中自动适配 PDF 默认关闭，需要时点击画布“适合”或开启该选项。

## 教程会影响正式任务或系统偏好吗？

系统介绍和系统设置专题不载入示例，其他专题载入 000207 预解析工作区。开始需要示例的专题前先保存正式任务。教程自身只讲解并定位界面，不自动执行改号、保存或恢复默认设置；退出教程后实际调整系统设置仍会立即生效。

批量专题自动打开表格、切换列视图并展开统一修改区域；设置专题自动打开对应分类。退出时关闭没有未保存编辑的教程批量弹窗及教程设置弹窗。可使用左右方向键浏览，Esc 或 × 退出。示例编辑和保存只进入本地草稿，不改变内置预解析数据；教程参考文件按页加载。

## 新登录为什么让原窗口退出或失去页面锁？

同一账号只允许一个有效登录会话，新登录替换旧会话并释放原会话的页面锁。多人核对使用各自账号，在同一任务不同页面工作；失去锁的页面会转为只读。保存和批量修改都会检查锁与版本，防止旧窗口覆盖新结果。

## 保存结果待确认是什么意思，能再次点击保存吗？

表示浏览器没有收到完整回执，服务器可能已经保存，也可能尚未完成，不能直接当作保存失败。普通保存写入最多等待 45 秒；出现不确定结果后，系统再读取服务器页面核实本次请求标识和版本，核实读取也受 30 秒时限限制。确认成功会正常显示已保存，不自动再次写入；无法确认时保留当前修改。

恢复网络后可以再次点击保存，系统先核实上次结果。若上次已经成功且当前提交内容相同，直接确认完成；若等待期间又有新修改，会保留新修改并提示再次保存。明确点击重试才可能再次发出写入，仍使用版本校验，避免旧请求和重试各保存一次。切页或保存并关闭遇到待确认结果时，不会把工作区当作全部保存成功。

## 后台自动标识占比是否就是识别准确率？

不是。管理员业务统计显示保留在结果中的自动标识数量占参与标识总数的比例，页面核对率依据保存审核记录统计；它们不能证明工程正确性。后台首页可按日期、项目、用户、人工操作筛选，并在效果排行切换项目与图纸视图。导出按钮导出当前筛选下的项目统计 CSV；审计页则导出操作记录。时间统一按北京时间显示。
