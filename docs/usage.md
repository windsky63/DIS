# 使用指南

## 推荐流程

访问 `/login` 登录系统；登录成功后进入 `/main` 图纸工作台。直接访问需要认证的工作台或后台地址时，系统会先跳转到登录页，并在登录成功后返回原目标地址。

1. 登录系统并上传待标识 PDF；单文件任务可设置分析页码范围。
2. 根据工程资料选择对照 PDF 或 PCF；没有参考资料时可直接分析。
3. 提交任务，在任务队列的“解析任务”中查看上传、排队、参考资料和设计页处理进度。
4. 恢复已完成任务，先确认设计页与对照页关系，再核查候选对象和编号。
5. 使用拖动、改号、人工新增、复制粘贴、编号顺延或批量表格修正结果；误识别可删除并撤销。
6. 保存当前结果，或使用“保存并关闭”保存、释放页面锁并返回任务列表。
7. 导出 CSV 或带标识 PDF；工程结束后按数据管理要求归档或删除任务及浏览器草稿。

仅上传待标识 PDF 也能执行图元扫描，但缺少独立参考拓扑时应加强人工复核。

## 选择任务方式

| 入口 | 适用场景 | 完成后的结果 |
| --- | --- | --- |
| 智能编号 | 希望立即进入识别与核对流程 | 图元识别、对照匹配及自动编号结果 |
| 推入解析队列 | 提前准备图纸供后续核对 | 同样执行解析，在队列查看进度并恢复 |
| 直接落图 | 只需人工标注，或不希望自动识别 | 优化后的设计底图与人工标注工作区，不解析对照资料、不自动生成标识 |

直接落图也会创建服务器任务，在“落图任务”分类中恢复、归档和删除。PDF 对照解析须先选择对照 PDF；已有任务打开时，三个创建入口都会禁用，请先“保存并关闭”当前工作区，再准备另一任务。教程示例已预解析，无需再次提交。

## 参考资料如何选择

- 对照 PDF 适合已有标号图、竣工图或施工单位出图的场景。系统会从参考页提取编号、圆框和引线，并依据 ISO 号、页序、坐标及拓扑关系映射到设计页。
- PCF 适合需要工程坐标、构件语义和连接拓扑的场景，不依赖参考图上的可见编号框；解析器降级时仍可使用基础结果，但应加强人工复核。
- 两者都没有时仍可识别设计图自身的候选对象，但不能恢复参考编号。若两种资料都具备，应优先选择与当前工程版本一致、内容完整的一种，避免旧版资料造成错误匹配。

## 输入与输出

| 输入 | 是否必需 | 用途 |
| --- | --- | --- |
| 待标识 ISO PDF | 是 | 页面解析、图元识别和标识底图 |
| 对照 PDF | 否 | 恢复既有编号并辅助页面及对象匹配 |
| PCF | 否 | 提供工程坐标、构件语义和连接拓扑 |

| 输出 | 内容 |
| --- | --- |
| 分析 JSON | 页面身份、候选对象、匹配关系、编号及人工修改 |
| CSV | 核对后的编号清单 |
| 带标识 PDF | 原图、可视化标识和内嵌可编辑数据 |
| 训练样本归档 | 用于规则研究和问题复现的任务数据包 |

## 项目与多家施工单位规则

从顶部“切换项目”菜单，点击弹窗顶部“当前识别项目”右侧的规则图标，进入项目识别规则。前端只支持切换项目、查看规则和选择出图来源，不提供新增、编辑、删除、导入或保存规则的入口；系统设置中的焊口符号研究配置入口及项目共用设计图参数编辑区已移除。设计图识别参数和组件规则以只读方式展示；EP3D 展示项目配置项、固定适配器基础阈值和组件识别说明，并可展开查看原始配置。每个解析任务和草稿仍保存当次规则快照，恢复旧任务不会自动覆盖项目规则库。

默认提供“EP3D 出图”和“施工单位出图”。规则详情以只读清单显示编号表达式、圆框尺寸、颜色、引线间隙和折线段参数；已有多家施工单位规则时可分别查看和选择。“逐文件指定出图来源”用于同一任务混用不同出图方对照 PDF 的场景：每份文件可以单独覆盖默认对照来源，例如默认使用 EP3D 规则时，仅把某份施工单位文件指定为施工单位规则。清空某文件的选择后恢复使用默认规则。该选择只决定后续解析采用哪套识别规则，不修改规则参数，也不改变已有解析结果。重新上传不同文件后请重新指定来源，避免沿用旧文件对应关系。规则定义由代码配置和任务配置提供，不在前端界面维护；已有浏览器规则数据不删除，继续兼容读取。

设计图识别规则和对照图识别规则默认折叠，点击分区标题可分别展开或收起。重新打开弹窗、切换项目或切换对应出图规则后，该分区恢复折叠。项目及来源选择器、逐文件来源选择仍直接显示。

施工单位适配器识别红色圆圈框内的编号。圆框与引线允许留间隙，也支持有短间隙的分段/折线引线；直接以引线末端作为焊口坐标，不要求末端落在工艺管线或焊口黑点上。间隙及尺寸单位是 PDF 点（1/72 英寸）。只有圆框而没有可关联引线时不会生成焊口。当前支持矢量 PDF 与原生可提取文字，扫描图片或转曲编号需要另行接入 OCR。

配置先经前端与后端校验，再进入解析队列。切换规则只影响后续解析，已有结果需要重新解析；旧算法结果不会被新任务静默复用。

## 画布操作

- 单击标识：选中对象并在右侧查看证据。
- 选中标识后，点击右侧“顺延编号”或按默认 `Ctrl+F`，可保持当前编号不变，并将当前页同类、同前后缀且数字不小于当前编号的其他标识统一加 1。例如选中新插入的 `F4` 后，原 `F4/F5/F6` 会变为 `F5/F6/F7`；该操作支持撤销。快捷键可在系统设置中修改，但会强制保留 `Ctrl` 修饰键。
- 双击编号：编辑编号文字。
- 拖动编号框：改变标识框位置和引线终点。
- 拖动半透明端点：修正引线起点。
- 在画布空白处按住左键或中键拖动：平移画布。滚轮上下翻页；`Ctrl+滚轮` 以指针为中心缩放。
- `W`、`V`、`F`、`S`：进入对应类型修改模式。
- `M`：进入“其他”标识修改模式，显示右侧“其他”分类，并可新增或修改其他标识。分栏圆形只是其他标识的一种可选外形。
- `A`：在 W、V、F、S、M 模式中，于鼠标位置新增对应类型；M 新增的是采用当前“其他”外形设置的其他标识。
- `Ctrl+C` / `Ctrl+V`：复制选中标识，并粘贴到鼠标位置。
- `Ctrl+Z` / `Ctrl+Y`：撤销或重做。
- `Backspace`：删除选中标识。
- `D`：进入或退出区域删除模式。W/V/F/S/M 修改模式下只删除对应的焊口/阀门/法兰/支架/其他标识；默认模式删除所有类型。以定位点是否落在选框内判断，`Esc` 退出，`Ctrl+Z` 撤销。进入区域删除不会清除当前修改类型。
- `Esc`：取消当前编辑、选择或修改模式。

右侧“重新优化当前页标识位置”是页级操作，无需先选中对象。点击后会重新排列当前页的全部标识，尽量避让正文文字、管线、对象锚点、其他标识和引线；它不会自动改动其他页面。解析任务完成前，Worker 已执行一次初始布局优化，撤销、重做、拖动或其他编辑不会再次自动触发优化，需要时应手动点击该按钮。

系统设置 → 标识默认设置 → 标识编辑操作方式，可以选择“按键新增”或“拖拽新增”，选择会保存在当前浏览器中。按键新增保留原操作：进入对应类型的编辑模式后，鼠标定位并按 `A` 新增，左键可平移画布。拖拽新增时，进入编辑模式后在定位点按住左键，向标识框位置拖动并松开，拖动期间会预览引线；引线方向和长度由起点与终点决定。此时左键不再平移画布，可使用中键平移；系统设置和右侧面板都会隐藏“新增标识引线”设置。拖拽方式下 `A` 不执行新增，退出编辑模式后恢复左键平移。单击、取消拖拽或切换页面不会新增标识。

### 批量修改标识

右侧“图纸标识”区域中，“重新优化当前页标识位置”下方的“批量修改标识”按钮打开当前任务全部页面的标识表格。打开前先保存画布中的待保存页面。可按页码、类型或编号搜索筛选；“内容与状态”编辑编号、分栏下栏内容、对照编号及是否参与标识，“标识外观”编辑外形、颜色、框尺寸、字号、线宽与填充透明度。每个表格页显示 15 行，分页控件独立放在表格下方，最多显示 5 个数字页码。表头复选框选择或取消全部筛选结果，包含所有表格分页；部分结果已选时显示半选状态。取消当前筛选结果不会影响其他已选标识；未设置筛选时可通过表头复选框全选或全部取消。展开“统一修改选中标识”，可按图纸页码和原始表格顺序生成连续编号，或对选中行统一设置内容、参与状态及外观；外观留空项保持不变。

框尺寸（18–64）和字号（7–24）独立设置。圆形、菱形和分栏圆形不会因长编号或字号增加而扩大，长编号按框内空间自动缩小文字，分栏圆形同时考虑上下栏内容。矩形保留原有按文字长度扩展宽度的规则。已有框尺寸继续生效，缺失时使用分类默认值；画布、布局优化和 PDF 导出使用相同尺寸规则。右侧分类设置将框尺寸和字号放在同一行，线宽和颜色放在同一行。

页面筛选支持全部页面、单页和“页码范围”。选择“页码范围”后填写起始页、结束页，包含两端页码，可与类型和搜索条件组合；范围无效时提示错误并禁用表头全选。表头复选框选择范围内符合全部筛选条件的所有标识。

表格中的修改先保留在表格内，点击“保存批量修改”后逐页保存。保存时检查每页的核对锁及页面版本：被其他窗口核对或版本已经变化的页面不会覆盖，失败的修改保留在表格中；其他页面可正常保存。版本冲突应关闭并重新打开表格，再基于最新数据修改。点击遮罩、关闭按钮或按 Esc 时，未保存的修改会提示保留或放弃；没有待保存修改时可直接退出，保存过程中暂时禁止退出。底部保留“还原未保存修改”和“保存批量修改”按钮。已保存的批量修改可在对应图纸页使用现有撤销、重做功能。表格设置的外观仅作用于改动的标识，右侧选中对象显示“仅影响当前选中对象”；未设置独立外观的标识仍采用原有分类外观。

快捷键可在系统设置中修改。复制粘贴在系统内部完成；编辑编号输入框时仍使用浏览器的普通文本剪贴板。

右侧设置卡片只调整当前任务，可分别设置焊口、阀门、法兰、支架和其他标识的外观、新增编号前缀、后缀、起始数字及新增引线长度。外形下拉框中的“默认”跟随系统设置里该分类选择的外形。起始数字允许留空，留空时新增编号只拼接前缀与后缀。选择分栏圆形时，上栏和下栏分别配置前缀、后缀及起始数字；每次新增会让两栏各自按其规则同步递增。人工新增编号与系统自动识别编号使用不同序列，首次新增严格使用设定的起始数字：焊口在当前连续编辑过程跨页递增，例如第一页从 20 新增到 30 后，第二页从 31 开始；阀门、法兰、支架和其他标识按页分别计数，每个新页面从设定起始数字开始，返回原页面则继续该页序列。修改前缀、后缀或起始数字会按新规则重新计数；打开或恢复另一任务也会建立新计数器，不检查该任务已有标识。默认焊口无前缀，阀门为 `V`、法兰为 `FL`、支架为 `SP`、其他标识上栏为 `M`，起始数字均为 `1`。

系统设置中的“标识默认设置”是登录用户以后新建任务所采用的常态化默认值。修改某一类型的系统默认值时，该类型设置也会立即同步到当前打开的任务；旧任务和草稿中已经保存的任务级设置仍随任务恢复。右侧任务设置不会反向覆盖系统默认值。

系统设置底部的“恢复系统默认设置”会在二次确认后恢复浅色主题、左右区域、消息开关、分页、对照图选项、画布性能、文件切换、标识默认外观与新增编号、引线长度和快捷键。恢复后的标识默认值会同步到当前任务；该操作不会删除任务、草稿、账号、审计日志或服务器环境配置。

### 界面、消息与默认设置

系统设置目录包含“界面与 Header”“工作区与文件”“标识默认设置”“快捷键”和“其他设置”。界面与 Header 中分别控制操作信息和错误信息，二者默认开启，信息默认在底部显示；已有用户的手动选择继续保留。关闭操作信息不会隐藏错误提示，两个选项独立保存在当前浏览器中。可调整提示位置、Tooltip 与顶部按钮显示，系统设置入口始终保留；教程或队列入口隐藏后，可在此重新开启。

左右抽屉可分别选择紧凑、标准或宽松宽度，也可通过抽屉标题栏齿轮调整。自动适配 PDF 默认关闭，可在工作区与文件中开启；手动“适合”仍可随时使用。快捷键速查显示当前配置，教程中的按键是默认值，已自定义时应以速查面板为准。

系统设置中的“界面主题”提供浅色、深色两种模式，默认浅色；选择后立即生效并保存在当前浏览器。独立对照图窗口同步使用同一主题。浅色主题的顶部栏和左侧选中按钮采用接近白色的背景。

PDF 翻页采用渐进渲染。高清位图缓存命中时直接显示高清；未命中且单页预计超过约 400 万像素时，先显示低分辨率预览，页面稳定约 180 毫秒后再替换为高清位图。“节省内存”档位保留预览分辨率，不强制执行第二次高清渲染。渐进渲染只改变画布底图的临时像素密度，不影响标识坐标、识别结果、保存数据或导出 PDF。

同屏对照时优先显示待标识设计图，再补充对照图。对照页请求尚未完成时先预留右栏；切换到另一份对照 PDF 时，也先显示设计图再等待文档打开。对照图到达后按实际尺寸更新右栏，保持设计图坐标和当前缩放、平移，不再次自动适配；需要同时查看完整两图时可点击“适合”。对照加载失败保留设计图并提示错误，旧页面的迟到结果不能覆盖当前页。提前显示底图不跳过页面保存及核对锁检查，可编辑状态仍由协作流程决定。后台预取只立即处理下一张设计页，不再同时预取前一页和多张对照页；对照图需要翻页稳定约 550 毫秒后才进入浏览器空闲预取。继续翻页会取消尚未开始或正在执行的旧页升级与预取任务。

## 多人核对与保存

- 每位核对人员进入页面时获取该页独占锁；同一任务的其他页面仍可由其他人编辑。
- 默认租期为 180 秒，每 30 秒心跳续租；续租成功后从当时重新延长 180 秒。未续租而到期的锁可由其他窗口取得。
- 编辑只改变当前浏览器工作区。点击其他页后会先显示目标页，再保存原页；保存失败时自动回退到原页，本地修改保持不变并提示重试。也可随时点击“保存”。
- “保存并关闭”只有在保存成功后才释放锁和关闭工作区。
- 页面存在未保存修改、正在保存或锁状态不确定时，关闭浏览器会出现确认提示。
- 页面 revision 冲突时旧版本提交会被拒绝，不会覆盖新结果。
- 普通 JSON 读取请求最多等待 30 秒，普通写入最多等待 45 秒；导出请求最多等待 120 秒。超时会中止浏览器等待，上传、PDF 分段读取和 AI 流式对话使用各自链路，不套用这组普通请求时限。
- 页面保存超时、连接中断或回执不完整时，会读取服务端页面核实本次保存请求标识和版本。确认已保存则正常结束，不自动重发保存；无法确认时保留修改并显示“保存结果待确认”。网络恢复后再次点击保存，先核实上次结果，再处理当前修改。等待期间又有新编辑时，只确认已提交的那一版，新编辑继续保留为待保存。
- 页面按钮颜色用于提示核对完整度，不代表已经完成工程确认。

## 任务队列与恢复

- 顶部栏最左侧的节点状态按钮同时显示图元引擎连接状态，并打开“任务队列”弹窗。弹窗打开时自动刷新，也可使用右上角刷新按钮重新读取状态。
- 任务队列顶层分为“解析任务”、“落图任务”和“已归档”；“已归档”内再按解析任务和落图任务分类。各分类独立分页、恢复和归档，不会将直接落图结果与对照解析结果混在同一列表。状态汇总区显示当前分类的运行数、等待数和并发槽位。
- 每个任务行显示文件名、创建时间、创建人、状态与解析进度。任务名显示宽度限制为 260 像素，超出后显示省略号，悬停可查看完整名称。等待任务可上下调整顺序；正在解析的任务可取消；完成任务可恢复核对或归档；符合条件的任务可永久删除。
- 点击任务行会展开所属项目、图纸页数、参与审核人数、已审核页数和最近逐页修改记录。点击行尾操作按钮只执行对应操作，不会展开任务；展开另一任务时原详情自动收起。
- 任务取得编号后已经进入持久队列，可以关闭上传页面；服务恢复后 Worker 会继续处理。
- 完成任务可以直接恢复核对，无需再次上传原图和参考资料。
- 归档只改变列表分类，不删除数据；永久删除会移除任务文件和解析结果。
- 浏览器草稿、服务器任务和标识 PDF 内嵌数据构成三条恢复路径。
- 恢复浏览器草稿或 PDF 内嵌数据时，系统会逐页比较服务端版本。仅本地修改的页面恢复为待保存状态；若服务端也已更新，则先列出冲突页，由用户选择保留服务端结果、使用草稿逐页加锁覆盖，或取消恢复。服务端任务或页面已不可用时，只恢复本地副本并明确标记为待保存。
- 手动“保存”会依次保存当前工作区的全部待保存页面，最后只写入一次浏览器草稿；任一页面失败时保留工作区和未保存内容。“保存并关闭”只有全部待保存页面处理成功后才关闭。
- 删除浏览器草稿后会自动回收不再被任何草稿引用的 PDF/PCF 文件；打开草稿管理器时也会清理升级前遗留的孤儿文件。多个草稿共享的文件会继续保留。
- 系统设置中的“上传设计图时清除已选对照文件”默认开启，避免跨任务误用参考资料。
- 工程文件夹和对照文件夹每次最多接收 1000 个文件；点击选择和拖拽使用同一上限，超限时拒绝整次选择并保留当前工作区。

任务长时间停留在“等待”或“排队”时，先打开解析队列确认前方是否已有运行任务，再由管理员检查 `/api/health` 的 `analysisWorkers`。值为 `0` 表示没有存活 Worker，任务会保持等待但不会丢失；恢复 Worker 后会继续处理。若队列已达到 `DRAWING_MARK_RECOGNITION_MAX_PENDING_ANALYSES` 上限，应等待、取消不再需要的任务或由管理员调整容量。任务显示“失败”时查看失败原因后重新提交，避免反复提交同一组大文件占满队列。

## 界面与屏幕适配

主工作区面向桌面浏览器，按 1024、1100、1366、1440 像素及更宽屏幕分级适配。宽度不超过 1440 像素时，画布工具栏自动分成两行，并隐藏次要上下文标签、缩窄左右抽屉；不超过 1366 像素时进一步隐藏右侧汇总指标；不超过 1100 像素时抽屉缩至紧凑宽度。超过 1440 像素时左右抽屉按视口比例扩展，并限制在 250 至 320 像素。

登录、队列和设置类界面另有 760 像素及 640 像素断点，可在窄屏上重排内容。完整图纸核对需要同时容纳画布、分页和两侧信息，建议使用至少 1024 像素宽的浏览器窗口；手机窄屏适合登录、查看状态和简单操作，不作为完整编辑工作区的目标尺寸。

## 操作教程

- 新用户首次打开系统会自动进入分步教程，之后可通过顶部栏的指南针按钮再次打开。
- 教程目录包含“系统介绍”“图纸解析与编号”“对照核查与标识编辑”“人工新增与编号修正”“批量修改与跨页保存”“系统设置与默认外观”“任务队列与多人审核”七个专题。系统介绍逐项高亮顶部栏入口；系统介绍和系统设置无需载入示例，其余专题使用 000207。
- 批量专题自动打开表格，依次定位筛选、跨分页选择、统一内容、独立外观及保存区域，并切换内容和外观视图；设置专题自动打开对应设置分类。教程不自动改号、保存或调整偏好；退出时关闭由教程打开且没有未保存编辑的批量弹窗，以及教程设置弹窗。
- “任务队列与多人审核”会先高亮顶部栏队列入口，进入下一步时先打开并定位完整的解析队列弹窗，随后才依次定位页签、状态汇总、任务行操作和展开详情；教程会等待弹窗组件完成挂载，避免内部目标定位偏移。离开弹窗讲解后会自动关闭弹窗并回到画布。
- 需要示例的教程自动载入 000207 和预解析结果，不重新执行耗时解析。开始前先保存正式任务；请留意载入示例后的工作区切换。
- 教程参考 PDF 按当前页面关系懒加载。
- 教程修改只保存为当前浏览器草稿，不改变内置示例源数据。
- 可使用“上一步”“下一步”或左右方向键浏览，Esc 或右上角 × 退出。定位会等待相关内容加载完成、弹窗展开动画结束及边界稳定，再显示高亮；内容变高或滚动后重新定位。被隐藏或不可见的目标使用居中说明卡片并继续等待，弱网超过两秒也不会停止查找；关闭或切换步骤取消旧定位。

## AI 助手

- 顶部栏的“AI 助手”会结合当前工程输入模式、参考模式、页码、标识数量、修改模式和选中标识类型提供操作建议。
- 涉及系统功能、操作、技术机制、部署或排查时，助手会自动搜索经过批准的系统文档；界面依次显示分析、检索或读取状态。
- 回答通过流式接口逐段显示，并解析标题、列表、表格、引用、链接和代码块等 Markdown 格式；传输中断时保留已经收到的内容并显示错误原因。
- 使用了文档的回答会显示“参考资料”，其中包含真实文档标题、章节、相对路径和起始行；没有找到可靠依据时助手会明确说明。
- 输入框默认显示两行，可随多行文字自动增高，达到高度上限后在输入框内部滚动。
- `Enter` 发送，`Shift+Enter` 换行；中文输入法正在选字时不会触发发送。
- AI 只提供说明和操作指导，不会代替用户点击、上传、修改、保存、归档、删除或导出。
- 检索命中的项目系统文档片段会发送到已配置的 AI 服务；当前不会发送任务 PDF、PCF、识别结果、账号数据、审计日志或环境配置。

## 后台管理

系统生成的任务、审核、审计、登录、上传和页面锁时间统一记录为北京时间（UTC+8），并携带明确的 `+08:00` 时区偏移；管理后台、任务队列和草稿列表也固定按 `Asia/Shanghai` 显示，不受服务器或浏览器所在时区影响。

管理员点击顶部原有的用户信息入口后，可从用户弹窗中的“后台管理”进入 `/admin`。后台首页显示用户、有效登录会话、任务状态、解析 Worker、数据库大小、审核次数和 AI 密钥余额。每个账号只允许一个有效登录会话；新登录会替换该账号此前的会话并释放该账号原先持有的页面锁，旧浏览器会在下一次请求时退出登录。`/admin/users` 显示脱敏后的用户表；`/admin/sessions` 显示当前有效登录会话，最近 5 分钟内有操作的用户标记为“在线”，其余显示“暂离”，页面每 30 秒自动刷新；`/admin/database` 显示批准的业务表及记录数。后台不会显示会话令牌、Cookie、密码哈希、API 密钥或任务文件内容。

当前内置 `admin` 账号拥有管理员权限，普通注册账号只能使用工作台。AI 余额仅在使用官方 DeepSeek 地址时通过服务端查询；其他 OpenAI 兼容服务没有统一余额协议，后台会显示“不支持”，不会根据调用次数估算虚假额度。余额接口失败不影响工作台和 AI 对话。

后台首页增加业务统计，可按日期、项目、用户及人工操作类型筛选，查看处理图纸、页面核对率、自动标识占比、人工干预、任务成功率和失败任务。“效果排行”可切换项目与图纸视图；“导出”生成当前筛选的项目统计 CSV。自动标识占比表示当前结果中保留的自动标识比例，不等于识别准确率；页面核对率依据保存审核记录，不替代工程验收。审计页 `/admin/audit` 提供按日期、用户、来源、操作、任务与关键字筛选的操作时间线、详情和 CSV 导出；任务页 `/admin/jobs` 可检索状态与任务。

### 复制粘贴标识

先单击选中焊口、阀门、法兰、支架或其他标识，按 `Ctrl+C` 复制；将鼠标移到目标位置后按 `Ctrl+V` 粘贴。新标识保留原对象类型、编号、外观和引线相对位置，但会被标记为人工对象并清除参考匹配身份。编辑编号输入框时，复制粘贴仍用于普通文字。

## 使用边界与排查

- 当前核心流程更适合包含原生文字和矢量图元的 PDF；扫描版 PDF 的标题栏、编号框和引线识别能力会明显下降。
- 无参考资料时，系统只能依据设计图自身的视觉与拓扑证据生成候选，必须重点人工复核。
- 自动识别数量与参考数量不一致时，应核查证据来源，不应以参考数量为目标强行补齐。
- 出现“设计页无对照图”时，先检查两侧标题栏 ISO 号、页序后缀及文件命名。
- 出现“有对照页但无对象”时，再检查参考页对象提取和拓扑匹配结果。
- 大图纸首次打开未缓存页面时会按需加载；持续卡顿时应结合文件大小、页数、参考文件数量、浏览器内存和控制台错误定位。
