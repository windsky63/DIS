# 图纸标识识别系统 2.0

图纸标识识别系统是一套面向工业管道 ISO 轴测图的本地化识别、对照、编号与人工校对工具。系统以待标识设计图为工作底图，可结合已编号对照 PDF 或 PCF 数据恢复焊口及管件身份，并将自动识别结果、人工修改记录和源图纸一起保存，最终导出 CSV 或带标识 PDF。

系统适合单机或可信内网多人部署。所有自动识别和编号结果都应由工程人员复核后再用于生产。

## 系统功能

### 工程图纸与参考资料输入

- 支持单份待标识 PDF，也支持一次选择多份 PDF 组成工程任务。
- 单份 PDF 可限定分析页码，避免封面、目录等无关页面参与识别。
- 可独立分析设计图，也可附加已编号对照 PDF、PCF 文件或服务器 PCF 文件库。
- 支持图纸、参考资料和解析配置的任务级持久化，已完成任务无需重新上传即可恢复。

### 焊口与管件识别

- 识别主管上的黑色闭合焊口符号，并结合工艺管线投影过滤图签、材料表和普通几何圆。
- 识别阀门、法兰和支架，综合利用标识框、文字、引线、材料表语义及局部几何证据。
- 支持普通焊口、预制 X、承插焊/螺纹焊方括号等符号配置。
- 每个候选对象保留证据、置信度、参考身份和图元来源，便于人工核查。

### 页面关系、拓扑匹配与编号

- 从标题栏和文件名提取图纸身份，建立设计页与对照页之间的一对一或一对多关系。
- 综合主管骨架、分支结构、焊口次序以及阀门、法兰、支架等地标进行拓扑匹配。
- 优先继承可信的对照编号；没有直接身份时，按当前编号规则生成建议编号。
- PCF 可补充构件语义、工程坐标和连接关系，但不会替代 PDF 页面中的实际图元证据。

### 可视化核对与人工编辑

- 在同一画布查看设计图、对照提示、编号框、引线和识别端点。
- 支持拖动编号框、修改引线端点、双击编辑编号、排除误识别、恢复对象和人工补充遗漏。
- W、V、F、S 分别进入焊口、阀门、法兰和支架修改模式；M 模式可同时修改全部标识。
- 支持复制选中标识并粘贴到鼠标位置，保留类型、编号、外观和引线相对位置。
- 焊口、阀门、法兰和支架可独立设置形状、颜色、尺寸、字号、线宽和填充透明度。
- 右侧设置仅作用于当前任务；系统设置保存新任务默认值，并可一键恢复全部系统默认设置。
- 支持撤销、重做、页码跳转、缩放、平移和当前页标识避让优化。

### 任务队列与多人核对

- 上传后由独立 Worker 在后台解析，可查看等待、运行、完成、失败和归档状态。
- 支持调整等待顺序、取消任务、恢复已完成任务、归档和永久删除。
- 提供账号注册与登录；可信内网中的有效账号可访问全部任务。
- 页面采用独占编辑锁和独立 revision，不同人员可以同时核对同一任务的不同页面。
- 保存失败或版本冲突时不会覆盖服务器上的新结果。

### 保存、恢复与导出

- 编辑内容同时进入页面级后端保存和浏览器 IndexedDB 容灾草稿。
- “保存并关闭”会先保存当前结果、释放页面锁，再关闭工作区并返回任务列表；保存失败时保持任务打开。
- 支持从服务器任务、浏览器草稿或带编辑数据的标识 PDF 恢复工作区。
- 支持导出 CSV 和带可视标识的 PDF；标识 PDF 内嵌可继续编辑的数据。
- 后端自动生成训练样本归档，便于后续规则研究和问题复现。

### AI 助手与操作教程

- 登录用户可通过内置 DeepSeek AI 助手查询操作方法和当前工作区相关问题，回答内容以流式方式实时显示。
- 助手可按问题自动查阅经过批准的系统文档，并在回答下方列出实际参考的文档与章节。
- 会话按用户同步到服务器，浏览器同时保留缓存。
- 新用户可通过内置 000207 示例学习输入、解析、核对、保存和导出流程。
- AI 服务未配置时显示明确错误提示，不影响识别、校对和导出等核心功能。
